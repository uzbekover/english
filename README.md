# Сервисный английский

Тренажёр рабочих английских фраз для сервиса станков ЧПУ. Один файл, без сборщиков и зависимостей.

- **Обучение:** английская фраза → перевод → пауза, чтобы повторить вслух.
- **Проверка:** программа говорит по-русски, ты отвечаешь по-английски, ответ распознаёт браузер
  и сравнивает с эталоном по словам. Три попадания подряд — фраза выучена, её место занимает следующая.

Файлы:
- `index.html` — исходник (формат страницы claude.ai: без `<head>`);
- `docs/index.html` — его копия для GitHub Pages, собирается командой `./build.sh`.

Голос проверяется в Chrome, Edge и Safari, прогресс хранится в браузере устройства.
